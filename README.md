# Enchanted Portfolio

Build a heavily animated, dark-themed portfolio website using React.js, Framer Motion, Three.js, and Particles.js, optimized for mobile and desktop. The site should include fullpage seamless transitions with unique animation styles per page.

Sections (Each on separate pages with smooth animated transitions):
Hero + About Me Page:

Includes 3D animated icons (Three.js), an interactive particles background (Particles.js), and animated gradient blurs.

About section should feature my intro, profession, achievements in a smooth entrance animation (Framer Motion).

Call to Action Page:

With an animated button to "Contact" or "Hire Me", glowing effects, and motion blur on hover.

Downloadable Resume Page:

PDF resume link with stylish animation upon hover/click.

Projects Page:

Grid or carousel of projects with 3D hover animations (Three.js) and lazy loading.

My Skills Page:

Animated skill icons with counters or bars, showing proficiency using Framer Motion.

Contact Page:

Interactive email form (with validation) and animated send success.

Featured Articles Page:

Blog/article list with smooth load-in and fade effects.

Coding Profiles Page:

Showcase cards linking to LeetCode, GitHub, SkillRack, etc., with motion pop-ins.

Social Links Section:

Icons for LinkedIn, Instagram, GitHub, YouTube, Twitter, each animating on hover.

Visual/UX Requirements:
Animated gradient blur backgrounds.

Particles interact with mouse movement.

Each section/page should feel like a mini experience (not static).

Transitions should be cinematic and fluid (no jank).

Full responsiveness for mobile/tablets.
